# Plan4Flex Housing Management Module - Full Stack Implementation

## 📋 Proje Özeti

Multi-tenant SaaS platformu için konaklama (housing) yönetim modülü geliştirme.
İşçi tedarik firmalarının işçi konaklama yerlerini yönetmesine olanak sağlar.

**Tech Stack:**
- Backend: Node.js + Express
- Frontend: React + Tailwind CSS
- Database: PostgreSQL
- ORM: Prisma
- Authentication: JWT

---

## 🎯 MVP Özellikleri

### 1. House/Room/Bed Management (Ev/Oda/Yatak Yönetimi)

#### Database Schema:
```
Houses (Evler)
├── Rooms (Odalar)
│   └── Beds (Yataklar)
```

**Houses Tablosu Alanları:**
- `id` (UUID, Primary Key)
- `tenantId` (UUID, Foreign Key - Multi-tenant)
- `name` (String) - Ev adı
- `address` (String) - Sokak
- `houseNumber` (String) - Bina numarası
- `houseNumberAddition` (String) - Bina numarası eki (a, b, c)
- `postalCode` (String) - Posta kodu
- `city` (String) - Şehir
- `country` (String, default: 'NL') - Ülke
- `latitude` (Decimal)
- `longitude` (Decimal)
- `totalRooms` (Integer)
- `totalBeds` (Integer)
- `costPerWeek` (Decimal) - Haftalık ücret
- `costPerBedPerDay` (Decimal) - Yatak başı günlük ücret
- `ownershipType` (Enum: 'owned', 'rented', 'third_party')
- `status` (Enum: 'active', 'inactive', 'maintenance')
- `description` (Text)
- `internalNotes` (Text)
- `createdAt` (DateTime)
- `updatedAt` (DateTime)

**Rooms Tablosu Alanları:**
- `id` (UUID, Primary Key)
- `houseId` (UUID, Foreign Key)
- `roomNumber` (String) - Oda numarası (Örn: "45")
- `floor` (Integer) - Kat
- `roomType` (Enum: 'standard', 'family', 'single', 'shared', 'suite')
- `bedCount` (Integer) - Yatak sayısı
- `genderRestriction` (Enum: 'male_only', 'female_only', 'family_only', 'mixed')
- `isFamilyRoom` (Boolean) - Aile odası mı?
- `status` (Enum: 'available', 'occupied', 'oos', 'maintenance')
- `costPerDay` (Decimal)
- `createdAt` (DateTime)
- `updatedAt` (DateTime)

**Beds Tablosu Alanları:**
- `id` (UUID, Primary Key)
- `roomId` (UUID, Foreign Key)
- `bedNumber` (Integer) - Yatak numarası
- `status` (Enum: 'available', 'occupied', 'reserved', 'oos')
- `lastOccupiedBy` (UUID, Foreign Key to Workers)
- `lastOccupiedAt` (DateTime)
- `createdAt` (DateTime)
- `updatedAt` (DateTime)

**Workers Tablosu (İşçiler):**
- `id` (UUID, Primary Key)
- `tenantId` (UUID, Foreign Key)
- `firstName` (String)
- `lastName` (String)
- `gender` (Enum: 'male', 'female', 'other')
- `email` (String)
- `phone` (String)
- `address` (String)
- `nationality` (String) - Ülke kodu
- `status` (Enum: 'active', 'inactive', 'blocked')
- `createdAt` (DateTime)
- `updatedAt` (DateTime)

**Housing Reservations Tablosu (Konaklama Rezervasyonları):**
- `id` (UUID, Primary Key)
- `workerId` (UUID, Foreign Key)
- `houseId` (UUID, Foreign Key)
- `roomId` (UUID, Foreign Key)
- `bedId` (UUID, Foreign Key)
- `tenantId` (UUID, Foreign Key)
- `startDate` (Date) - Başlangıç tarihi
- `endDate` (Date, nullable) - Bitiş tarihi
- `checkInDate` (Date, nullable)
- `checkOutDate` (Date, nullable)
- `status` (Enum: 'pending', 'confirmed', 'checked_in', 'checked_out', 'cancelled')
- `dailyRate` (Decimal)
- `totalCost` (Decimal)
- `onVacation` (Boolean) - Tatilde mi?
- `belongingsInRoom` (Boolean) - Eşyaları odada mı?
- `description` (Text)
- `internalNotes` (Text)
- `confirmedBy` (UUID, Foreign Key to TenantUsers)
- `confirmedAt` (DateTime)
- `createdAt` (DateTime)
- `updatedAt` (DateTime)
- `createdBy` (UUID, Foreign Key to TenantUsers)

### 2. Housing Overview Screen (Konaklama Genel Bakış Ekranı)

**Features:**
- Tüm evleri listelemek
- Tarih bazlı doluluk durumu göstermek
- Filtreler:
  - 📅 Tarih seçici
  - 🏠 Ev seçimi (All/Specific)
  - 🛏️ Only empty beds (Boş yatakları göster)
  - 🌍 Milliyet filtresi
  - 🏙️ Şehir filtresi
  - 👤 Account manager filtresi
- 📊 Kapasite göstergesi (boş/dolu yatak sayısı)
- 🎨 Renk kodlu durum:
  - 🔴 Boş (empty)
  - 🟢 Dolu (işçi adı gösterilir)
  - 🟡 OOS (Out of Service - tamir/bakım)
  - 🔵 Mavi işaret = Erkek
  - 🟣 Pembe işaret = Kadın
  - 🟠 Turuncu = Yakında boş (checkout yakın)

**API Endpoints:**
```
GET /api/houses

  - tenantId (required)
  - date (YYYY-MM-DD, default: today)
  - houseId (optional)
  - cityId (optional)
  - showEmptyOnly (boolean)
  - nationalityFilter (optional)
  
  Response:
  {
    "success": true,
    "data": {
      "totalHouses": 21,
      "totalBeds": 397,
      "emptyBeds": 173,
      "occupiedBeds": 224,
      "houses": [
        {
          "id": "uuid",
          "name": "Geldernstrasse 13",
          "city": "Geilenkirchen",
          "totalBeds": 18,
          "rooms": [
            {
              "id": "uuid",
              "roomNumber": "45",
              "bedCount": 2,
              "beds": [
                {
                  "id": "uuid",
                  "bedNumber": 1,
                  "status": "occupied",
                  "worker": {
                    "id": "uuid",
                    "name": "Canny",
                    "gender": "male"
                  }
                },
                {
                  "id": "uuid",
                  "bedNumber": 2,
                  "status": "available"
                }
              ]
            }
          ]
        }
      ]
    }
  }

GET /api/houses/:houseId
  Response: Ev detayları

POST /api/houses
  Body: { name, address, postalCode, city, totalRooms, totalBeds, ... }

PUT /api/houses/:houseId
  Body: Güncellenecek alanlar

DELETE /api/houses/:houseId
```

### 3. Housing Reservation System (Konaklama Rezervasyon Sistemi)

**Features:**
- İşçiyi yatağa atama
- Tarih aralığı seçimi
- Otomatik kontroller:
  - ✅ Cinsiyet uyumu (aynı odada erkek-kadın kontrolü)
  - ✅ Aile odası kısıtlaması
  - ✅ Yatak kullanılabilirlik kontrolü

**Cinsiyet Uyarı Sistemi:**

Farklı cinsiyet + Farklı soyadlar = UYARI
```typescript
Seçenekler:
1. Evli çift olarak işaretle ✅
2. Ayrı odalara yerleştir
3. Yine de devam et
```

**API Endpoints:**
```
POST /api/reservations
  Body: {
    workerId: "uuid",
    bedId: "uuid",
    startDate: "2025-10-06",
    endDate: "2025-10-20",
    dailyRate: 30.00
  }
  
  Validations:
  - Yatak boş mu?
  - Tarih aralığında çakışma var mı?
  - Cinsiyet uyumu kontrolü
  - Aile odası kısıtlaması

GET /api/reservations?workerId=uuid&date=2025-10-06

PUT /api/reservations/:reservationId
  Body: Güncelleme verileri

DELETE /api/reservations/:reservationId
  Soft delete (checkoutDate'i set et)
```

## 📊 Database (PostgreSQL + Prisma)

**Prisma Schema:**
```prisma
model Tenant {
  id        String   @id @default(cuid())
  name      String
  email     String   @unique
  houses    House[]
  workers   Worker[]
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}

model House {
  id                    String   @id @default(cuid())
  tenantId              String
  tenant                Tenant   @relation(fields: [tenantId], references: [id], onDelete: Cascade)
  name                  String
  address               String
  houseNumber           String
  houseNumberAddition   String?
  postalCode            String
  city                  String
  country               String   @default("NL")
  latitude              Float?
  longitude             Float?
  totalRooms            Int
  totalBeds             Int
  costPerWeek           Decimal?
  costPerBedPerDay      Decimal?
  ownershipType         String   @default("owned")
  status                String   @default("active")
  description           String?
  internalNotes         String?
  rooms                 Room[]
  reservations          Reservation[]
  createdAt             DateTime @default(now())
  updatedAt             DateTime @updatedAt

  @@unique([tenantId, name, postalCode])
}

model Room {
  id                  String   @id @default(cuid())
  houseId             String
  house               House    @relation(fields: [houseId], references: [id], onDelete: Cascade)
  roomNumber          String
  floor               Int?
  roomType            String   @default("standard")
  bedCount            Int
  genderRestriction   String?
  isFamilyRoom        Boolean  @default(false)
  status              String   @default("available")
  costPerDay          Decimal?
  beds                Bed[]
  createdAt           DateTime @default(now())
  updatedAt           DateTime @updatedAt

  @@unique([houseId, roomNumber])
}

model Bed {
  id                  String   @id @default(cuid())
  roomId              String
  room                Room     @relation(fields: [roomId], references: [id], onDelete: Cascade)
  bedNumber           Int
  status              String   @default("available")
  lastOccupiedBy      String?
  lastOccupiedAt      DateTime?
  reservations        Reservation[]
  createdAt           DateTime @default(now())
  updatedAt           DateTime @updatedAt

  @@unique([roomId, bedNumber])
}

model Worker {
  id                  String   @id @default(cuid())
  tenantId            String
  tenant              Tenant   @relation(fields: [tenantId], references: [id], onDelete: Cascade)
  firstName           String
  lastName            String
  gender              String?
  email               String?
  phone               String?
  address             String?
  nationality         String?
  status              String   @default("active")
  reservations        Reservation[]
  createdAt           DateTime @default(now())
  updatedAt           DateTime @updatedAt

  @@unique([tenantId, email])
}

model Reservation {
  id                  String   @id @default(cuid())
  workerId            String
  worker              Worker   @relation(fields: [workerId], references: [id], onDelete: Cascade)
  houseId             String
  house               House    @relation(fields: [houseId], references: [id])
  roomId              String
  room                Room     @relation(fields: [roomId], references: [id])
  bedId               String
  bed                 Bed      @relation(fields: [bedId], references: [id])
  tenantId            String
  startDate           DateTime
  endDate             DateTime?
  checkInDate         DateTime?
  checkOutDate        DateTime?
  status              String   @default("pending")
  dailyRate           Decimal
  totalCost           Decimal?
  onVacation          Boolean  @default(false)
  belongingsInRoom    Boolean  @default(false)
  description         String?
  internalNotes       String?
  confirmedBy         String?
  confirmedAt         DateTime?
  createdAt           DateTime @default(now())
  updatedAt           DateTime @updatedAt
  createdBy           String?
}
```
