### 2. **Basic RBAC - 3 Role İçin Login Flow** 🔐 Öncelik

```
Mevcut roller:
- admin (Tenant Owner gibi - her şeyi görebilir)
- office_staff (HR Manager / Planner gibi)
- field_staff (Worker gibi)
```

**Replit yapmalı:**
- [ ] Login flow implementation (email/password)
- [ ] Session management (JWT)
- [ ] Role-based middleware
```javascript
// Örnek
function requireRole(role) {
  return (req, res, next) => {
    if (req.user.role !== role) {
      return res.status(403).json({error: 'Forbidden'});
    }
    next();
  };
}
```
- [ ] Basic permission check
```javascript
const permissions = {
  admin: ['*'],
  office_staff: ['workers.view', 'workers.edit', 'planning.*'],
  field_staff: ['profile.own', 'schedule.own']
};
```

### 4. **Worker Profile & Employment** 👷 Core Feature

**Replit yapmalı:**

**A) Worker Profile (Global)**
```javascript
// worker_profiles table
{
  id: uuid,
  first_name: string,
  last_name: string,
  email: string,
  phone: string,
  documents: jsonb,  // CV, sertifikalar
  skills: jsonb,
  created_at: timestamp
}
```

**B) Employment (Tenant-specific)**
```javascript
// employments table
{
  id: uuid,
  worker_profile_id: uuid,
  tenant_id: uuid,
  status: enum('active', 'inactive', 'former', 'invited'),
  start_date: date,
  end_date: date,
  job_title: string
}
```

**C) Private Data (Sensitive)**
```javascript
// employment_private_data table
{
  employment_id: uuid,
  salary: decimal,
  bank_account: string,
  contract_terms: jsonb,
  performance_reviews: jsonb
}
```

**İmplement edilecekler:**
- [ ] Worker CRUD operations
- [ ] Employment relationship management
- [ ] Access control (worker own data vs tenant data)
- [ ] Worker status transitions (active → inactive → former)

### 5. **API Endpoints - MVP** 🔌

**Replit yapmalı:**

```javascript
// Auth
POST   /api/auth/login
POST   /api/auth/logout
GET    /api/auth/me

// Workers (office_staff + admin)
GET    /api/workers              // List all workers
GET    /api/workers/:id          // Get worker detail
POST   /api/workers              // Create worker
PUT    /api/workers/:id          // Update worker
DELETE /api/workers/:id          // Deactivate worker

// Worker self-service (field_staff)
GET    /api/profile              // Own profile
PUT    /api/profile              // Update own profile
GET    /api/schedule             // Own schedule
GET    /api/documents            // Own documents

// Admin only
GET    /api/users                // User management
POST   /api/users                // Create user
PUT    /api/users/:id/role       // Change role
```
