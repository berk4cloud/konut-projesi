### **ADIM 3: Tenant Admin Oluşturma** 👤 (1 hafta)

**Replit yapmalı:**

```javascript
// 3. Tenant Users (Her tenant'ın kullanıcıları)
CREATE TABLE tenant_users (
  id UUID PRIMARY KEY,
  tenant_id UUID REFERENCES tenants(id),
  
  email VARCHAR NOT NULL,
  password_hash VARCHAR,
  
  first_name VARCHAR,
  last_name VARCHAR,
  
  role ENUM('owner', 'admin', 'user'),  // Şimdilik basit
  
  status ENUM('invited', 'active', 'inactive'),
  
  invited_at TIMESTAMP,
  invited_by UUID REFERENCES tenant_users(id),
  activated_at TIMESTAMP,
  
  last_login_at TIMESTAMP,
  
  created_at TIMESTAMP,
  
  UNIQUE(tenant_id, email)  // Aynı tenant'ta unique email
);
```

### **ADIM 4: Tenant Admin Panel** 🏢 (2 hafta)

**Replit yapmalı:**

**Multi-tenant routing:**
```javascript
// Subdomain routing
if (req.hostname === 'platform.arpdo.com') {
  // Platform admin
  return platformRoutes(req, res);
}

// Tenant routing
const subdomain = req.hostname.split('.')[0];  // "cova-bv"
const tenant = await getTenantBySlug(subdomain);

if (!tenant) {
  return res.status(404).send('Tenant not found');
}

req.tenant = tenant;
return tenantRoutes(req, res);
```
